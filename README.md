# SEO AI Toolkit

ابزار تحت وب برای رصد رتبه کلمات کلیدی، تحلیل رقابتی محتوا و بهینه‌سازی متادیتا — **بدون هیچ کلیک شبیه‌سازی‌شده یا ترافیک مصنوعی**. تمام داده‌های رتبه از API رسمی Google Search Console خوانده می‌شود و تحلیل‌ها با Claude (Anthropic) روی محتوای واقعی صفحات انجام می‌شود.

## چرا این ابزار به‌جای شبیه‌سازی کلیک؟

شبیه‌سازی کلیک/بازدید کاربر برای بالا بردن رتبه، نقض قوانین گوگل است و معمولاً منجر به پنالتی می‌شود. این ابزار به‌جایش سه کار مفید و کاملاً مجاز انجام می‌دهد:

1. **رصد واقعی رتبه** کلمات کلیدی از داده رسمی Search Console
2. **تحلیل رقابتی** محتوای شما در برابر رقبا با هوش مصنوعی
3. **پیشنهاد بهبود** عنوان و توضیحات متا بر اساس محتوای واقعی صفحه

## پیش‌نیازها

- Node.js نسخه ۱۸ به بالا
- یک کلید API از [console.anthropic.com](https://console.anthropic.com)
- دسترسی به پراپرتی سایت در [Google Search Console](https://search.google.com/search-console)

## نصب

```bash
npm install
cp .env.example .env
```

سپس فایل `.env` را باز کنید و مقادیر را پر کنید.

## راه‌اندازی Google Search Console (برای بخش رصد رتبه)

Search Console API با Service Account کار می‌کند، نه با اکانت شخصی گوگل. مراحل:

1. به [Google Cloud Console](https://console.cloud.google.com) بروید و یک پروژه بسازید (یا از پروژه موجود استفاده کنید).
2. در بخش **APIs & Services → Library**، عبارت «Google Search Console API» را جستجو و **Enable** کنید.
3. در بخش **IAM & Admin → Service Accounts**، یک سرویس‌اکانت جدید بسازید.
4. برای همان سرویس‌اکانت یک **Key** از نوع JSON بسازید و دانلود کنید.
5. فایل JSON دانلود‌شده را در مسیر `data/gsc-service-account.json` این پروژه قرار دهید (یا مسیر دلخواه را در `GSC_SERVICE_ACCOUNT_PATH` بنویسید).
6. ایمیل سرویس‌اکانت (چیزی شبیه `xxx@your-project.iam.gserviceaccount.com`) را کپی کنید.
7. در Google Search Console، وارد پراپرتی سایت خودتان شوید → **Settings → Users and permissions → Add user** → همان ایمیل سرویس‌اکانت را با دسترسی **Full** اضافه کنید.
8. مقدار `GSC_SITE_URL` در `.env` را دقیقاً همان‌طور که در Search Console نشان داده می‌شود بنویسید (مثلاً `sc-domain:capis.be` یا `https://capis.be/`).

> توجه: داده Search Console معمولاً با ۲ تا ۳ روز تاخیر به‌روزرسانی می‌شود؛ این محدودیت خود گوگل است، نه ابزار.

## راه‌اندازی Claude API (برای تحلیل رقبا و متا)

1. یک کلید از [console.anthropic.com](https://console.anthropic.com) بسازید.
2. آن را در `ANTHROPIC_API_KEY` داخل `.env` قرار دهید.
3. مقدار `ANTHROPIC_MODEL` را در صورت نیاز تغییر دهید (پیش‌فرض: `claude-sonnet-5`).

## اجرا

```bash
npm start
```

سپس مرورگر را باز کنید: [http://localhost:3000](http://localhost:3000)

برای توسعه با ری‌استارت خودکار:

```bash
npm run dev
```

## ساختار پروژه

```
seo-ai-toolkit/
├── server.js              # سرور Express
├── routes/api.js          # مسیرهای API
├── services/
│   ├── gsc.js              # ارتباط با Google Search Console
│   ├── ai.js                # ارتباط با Claude API
│   ├── scraper.js           # استخراج محتوای متنی صفحات
│   └── store.js             # ذخیره‌سازی محلی (JSON)
├── public/                 # فرانت‌اند (HTML/CSS/JS ساده، بدون فریم‌ورک)
├── data/                   # کلمات کلیدی، تاریخچه رتبه، فایل سرویس‌اکانت
└── .env                     # تنظیمات شما (این فایل را در گیت commit نکنید)
```

## بخش‌های ابزار

| بخش | کاری که می‌کند |
|---|---|
| داشبورد رتبه‌ها | نمودار میانگین موقعیت در طول زمان + جدول کلیک/نمایش/CTR هر کلمه |
| کلمات کلیدی | افزودن/حذف کلمات کلیدی که می‌خواهید رصد شوند |
| تحلیل رقبا | مقایسه محتوای شما با یک رقیب و پیشنهاد شکاف‌های محتوایی |
| بهینه‌سازی متا | پیشنهاد عنوان و متا-دیسکریپشن بر اساس محتوای واقعی صفحه |
| تنظیمات | بررسی وضعیت اتصال هر دو سرویس |

## نکته امنیتی

- کلید Anthropic و فایل سرویس‌اکانت گوگل فقط روی سرور شما (لوکال) نگه‌داری می‌شوند و هیچ‌وقت به فرانت‌اند ارسال نمی‌شوند.
- فایل‌های `.env` و `data/gsc-service-account.json` را در `.gitignore` قرار دهید (این پروژه از قبل این کار را کرده).
